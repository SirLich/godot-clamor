# Clamor

Clamor is an audio plugin for Godot, with a focus on sounds-as-resources. Currently, it relies on [godot_sound_manager](https://github.com/nathanhoad/godot_sound_manager) by Nathan Hoad, as a kind of sound-backend. The sound manager has been slightly modified to allow Clamor resources to be played. In the future I will replace this with my own implementation.

##

## Get Clamor

Clamor is not currently available in the asset library. Instead, it can be downloaded from github as a zip. You can also install it via  [Hyrax](https://github.com/SirLich/hyrax)H
